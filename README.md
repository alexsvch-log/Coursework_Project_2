### Требования
Для запуска и разработки проекта вам понадобятся:

* **Python 3.14+** (проект использует современные возможности типизации)
* **Poetry** — инструмент для управления зависимостями и виртуальными окружениями.

### Настройка окружения и зависимостей
Управление зависимостями осуществляется через Poetry (без использования requirements.txt).

**1. Клонирование репозитория**
```bash
git clone https://github.com/alexsvch-log/Coursework_Project_2.git
```
**2. Установка зависимостей**

```bash
poetry install
```
**3. Запуск и активация окружения**

Активация виртуального окружения: 
```bash
poetry shell
```
Запуск скриптов напрямую:
```bash
poetry run python main.py
```

### Инструменты разработки (Linting)
В проекте настроена автоматическая проверка качества кода (`black`, `flake8`, `mypy`). Все конфигурации линтеров объединены в файле `pyproject.toml`.

Если вы планируете использовать линтер flake8, то рекомендуется установить плагин командой 
```bash
poetry add flake8-pyproject
```
Файл .flake8 в проекте отсутствует.

В случае, если вы решите установить линтеры - black, flake8, mypy - в корне проекта расположен файл lint.bat. При выполнении команды: .\lint на терминале запускаются все линтеры сразу.

**1. Установка инструментов:**
```bash
poetry install --with lint
```
**2. Быстрый запуск всех проверок (Windows):**
```bash
.\lint
```

## Использование

Программа предоставляет интерактивный консольный интерфейс для работы с пользователем. 

Запуск главного сценария:
```bash
poetry run python src/main.py
```

### Демонстрация работы сценария:
1. **Выбор региона:** Введите название страны (например, `Spain`). Программа отправит запрос к *Nominatim API* для получения координат границ страны.
2. **Сканирование неба:** По полученным координатам отправляется запрос к *OpenSky Network API*.
3. **Фильтрация и Сортировка:** Введите количество самолетов для ТОП N, страны регистрации ВС (через пробел) и желаемый диапазон высот (например, `4000-12000`).
4. **Вывод и экспорт:** Программа выведет отсортированный по убыванию высоты (DESC) список самолетов и предложит полностью перезаписать файл актуальным ТОПом по пути `data/answers.json` в корне проекта.

### 🛡️ Отказоустойчивость (Design for Failure)
Если внешние публичные API недоступны, выдают сетевые ошибки (`Timeout`, `SSLError`), блокируют запросы (`403 Forbidden`) или исчерпали лимиты анонимных обращений (`429 Too Many Requests`), программа **не падает**:
* При сбое *Nominatim* — автоматически подставляется резервный квадрат Швейцарии.
* При сбое *OpenSky* — включается **режим симуляции (Mock)**, генерирующий расширенный радар из 10 разнообразных бортов для полноценной проверки логики приложения.


## Тестирование и покрытие (Coverage)
Запуск тестового набора:
```bash
poetry run python -m unittest tests/test_tracker.py
```

Проверка процента покрытия кода:
```bash
poetry run coverage run -m unittest tests/test_tracker.py
poetry run coverage report
```
